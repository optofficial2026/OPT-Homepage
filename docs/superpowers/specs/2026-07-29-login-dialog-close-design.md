# 관리자 로그인 창 자동 닫힘 설계

## 문제

직접 로그인 함수는 성공 시 로그인 창을 닫지만, 다른 탭 로그인이나 저장된 세션을 처리하는 공통 인증 확인 경로는 관리자 상태만 갱신한다. 이 경로로 인증되면 로그인 창과 관리자 도구가 동시에 표시된다.

## 변경

`SiteContext`의 공통 사용자 검증 함수에서 `admin_profiles` 조회 결과가 관리자일 때 `loginOpen`을 `false`로 바꾼다.

- 관리자 확인 성공: 로그인 창을 닫고 관리자 도구를 표시한다.
- 로그인 실패 또는 비관리자: 기존 오류와 로그인 창을 유지한다.
- 로그인 폼, 인증 API, 권한 정책은 변경하지 않는다.

## 검증

- 공통 인증 경로가 관리자 확인 성공 시 로그인 창을 닫는지 회귀 테스트로 확인한다.
- 기존 비관리자 로그아웃·편집 모드 종료 동작을 유지한다.
- 전체 테스트, 타입 검사, 프로덕션 빌드를 실행한다.
- 운영 환경에서 로그인 창과 관리자 도구가 동시에 표시되지 않는지 확인한다.
