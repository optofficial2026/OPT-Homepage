# 세미나 자료 카드 설계

## 목표

세미나·강의 자료를 단순 `자료 보기` 링크가 아니라 제목·종류·설명·행동이 드러나는 자료 카드로 최대 5개까지 관리한다.

## 자료 구조

세미나 상세 JSON에 `resources` 배열을 추가한다.

```ts
type SeminarResource = {
  id: string;
  title: string;
  kind: 'PDF' | 'SLIDE' | 'VIDEO' | 'WEB' | 'CODE';
  description: string;
  url: string;
};
```

기존 `resourceUrl`은 삭제하지 않는다. `resources`가 비어 있고 기존 URL이 있으면 `외부 자료`라는 WEB 카드로 표시해 기존 데이터를 보존한다. 별도 DB 마이그레이션은 하지 않는다.

## 관리자 입력

- 자료는 최대 5개까지 추가한다.
- 각 자료에 제목, 종류, 짧은 설명을 입력한다.
- PDF·PPT·PPTX는 파일을 직접 업로드할 수 있다.
- 영상·노션·웹·코드는 URL을 입력한다.
- 등록된 자료는 미리보기 카드로 확인하고 개별 삭제한다.
- 파일은 Supabase의 기존 `content-media` bucket에 저장하며 최대 20MB로 제한한다.

## 공개 상세 페이지

각 자료 카드는 종류 badge, 제목, 설명, 구체적인 버튼을 표시한다.

- PDF: `PDF 열기`
- SLIDE: `슬라이드 다운로드`
- VIDEO: `영상 보기`
- WEB: `웹 자료 보기`
- CODE: `코드 보기`

링크의 접근 가능한 이름에는 자료 제목과 행동을 함께 포함한다. 자료가 없으면 `관련 자료` 소제목 아래 `준비 중입니다.`를 유지한다.

## 검증

- 최대 5개 제한과 파일 형식·20MB 제한을 자동 테스트한다.
- 기존 `resourceUrl` fallback을 테스트한다.
- 관리자 폼의 자료 추가·삭제와 파일/링크 입력을 확인한다.
- 상세 카드의 종류·설명·구체적인 버튼 문구를 확인한다.
- 전체 테스트, 타입 검사, Pages build와 배포를 확인한다.
