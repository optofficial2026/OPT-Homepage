# 활동 연혁 스크롤바 디자인

## 목표

활동 연혁의 스크롤 동작과 레이아웃은 유지하면서 운영체제 기본 스크롤바를 OPT의 청록·라임 색상에 맞는 얇은 네온 스타일로 교체한다.

## 디자인

- 연혁 스크롤바 너비는 5px로 제한한다.
- 트랙은 투명하게 두어 기존 배경과 자연스럽게 연결한다.
- thumb는 청록에서 라임으로 이어지는 색상과 둥근 모서리를 사용한다.
- hover 시 thumb가 조금 더 선명해지게 하되 크기와 레이아웃은 바꾸지 않는다.
- Firefox에서는 브라우저가 지원하는 단색 `scrollbar-color`를 사용한다.

## 변경 범위

- `src/index.css`의 `.timeline-scroll` 스타일만 수정한다.
- 연혁 데이터, 정렬, 스크롤 위치, 컴포넌트 구조는 변경하지 않는다.
- 다른 스크롤 영역과 관리자 편집창에는 적용하지 않는다.

## 검증

- 기존 테스트, 타입 검사, 빌드를 실행한다.
- 데스크톱에서 연혁 스크롤 동작과 hover 상태를 확인한다.
- 모바일에서 레이아웃이 바뀌지 않았는지 확인한다.
